# 使用指南

## 启动与配置

安装 Python 3.10+，在项目目录运行 `python app.py`，Windows 也可双击 `start.bat`，macOS / Linux 可执行 `bash start.sh`。浏览器未自动打开时使用终端输出的完整链接。

Windows 启动器依次尝试项目虚拟环境、系统 Python，再尝试已有的 Codex 内置运行时作为兼容回退；使用本项目不需要安装 Codex。Linux / macOS 启动器优先使用项目虚拟环境，然后使用系统 Python。

填写 API 根地址（例如 `https://api.openai.com/v1`）、该服务商的 API Key，以及实际可用的模型名称。首次使用不预填模型，也不提供内置候选名单；可以手动填写，或点击“获取列表”后选择。展开列表始终显示本次获取的全部上游模型，不受输入框已有内容影响；选中模型才会更新输入框。模型列表只确认服务商报告的名称，不保证该通道实时可用。以后打开同一站点时，浏览器可恢复你自己保存的模型设置。

模型名中的 `-4k` 之类后缀可能由服务商自定义。程序原样发送模型名，不自动改名或切换模型。

## 上传与编辑

支持最多 16 张 PNG / JPEG / WebP，单张不超过 20 MB，合计不超过 40 MB，每张不超过 16,777,216 像素。这是客户端限制；服务商可以有更严格限制。

第一张可作为待修改的原图，后续图片提供风格或内容参考。示例：

> 保留图1的人物、表情和构图，将背景改为夜晚街景，参考图2的蓝紫色调。

有参考图片时发送 `/images/edits` multipart 请求：单张字段 `image`，多张字段 `image[]`。没有参考图片时发送 `/images/generations` JSON 请求。描述原样提交；模型根据描述决定如何参考或修改。

点击结果下方的“用作参考 / 继续修改”，会把结果追加到参考图列表。移除图片后编号会重新排列，请同步检查描述。只修改新结果时可先清空参考区。

本工具不包含画笔选区、蒙版绘制或精确像素编辑。模型可能重新生成整个画面，不能保证未提及区域完全不变。

## 输出设置

| 设置 | 参数 | 选项 |
| --- | --- | --- |
| 尺寸 | `size` | 默认省略、`auto`、预设宽高、自定义宽高 |
| 画质 | `quality` | 默认省略、`auto`、`low`、`medium`、`high`、`xhigh`、`max` |
| 规划强度 | `complexity` | 默认省略、`low`、`medium`、`high` |
| 格式 | `output_format` | 默认省略、`png`、`jpeg`、`webp` |
| 背景 | `background` | 默认省略、`auto`、`opaque`、`transparent` |
| 数量 | `n` | 默认省略或 1–4 |
| 压缩参数 | `output_compression` | 仅 JPEG / WebP，0–100，留空省略 |
| 返回方式 | `response_format` | 默认省略、`b64_json`、`url`，须服务商支持 |

官方对 GPT-Image-2.6 的规划强度有明确说明；其他模型或服务商不一定支持。画质控制渲染细节，规划强度控制绘图前的规划计算量，两者独立。参数报错时恢复默认会省略可选参数，保留参考图片。

透明背景需 PNG 或 WebP；JPEG 无法保存透明通道。

## 4K

4K UHD 横图为 `3840x2160`，竖图为 `2160x3840`。本客户端的自定义栅格输出尺寸校验规则：

- 宽、高必须是 16 的正整数倍，每边最多 3840。
- 宽高比在 1:3 至 3:1 之间。
- 总像素在 655,360 至 8,294,400 之间。

`3840x2160` 正好为 8,294,400 像素；`4096x4096`、`3840x3840` 超过限制。方形高分辨率预设为 `2880x2880`。

官方指南把超过 `2560x1440` 的尺寸标为实验性，服务商通道可能不支持。模型名称或高画质选项不能保证分辨率。程序会显示文件实际宽高，不会将小图放大成 4K；返回尺寸与请求不同会提示。

“设为 4K 横图”仅设置尺寸、1 张和 600 秒超时，不修改画质或模型，也不立即发送请求。

## 常见错误

| 错误 | 检查方向 |
| --- | --- |
| 400 | 参数、模型支持范围、图片格式与尺寸 |
| 401 / 403 | API Key、账号权限、服务商访问限制 |
| 404 | API 根地址、模型名、编辑接口是否可用 |
| 413 / 415 | 图片大小、图片格式、multipart 上传支持 |
| 429 | 余额、配额、请求频率 |
| 502 / 503 | 服务商网关或上游模型通道 |
| 504 / 超时 | 服务商处理时间、网关超时、本地网络 |

`502: Upstream service temporarily unavailable` 表示网关的上游调用失败，不能仅凭此判断是尺寸不支持。延长本地超时无法强制延长服务商网关超时。

程序不会自动重试、改模型或把失败的编辑请求转换成文生图。超时或网关错误后服务商仍可能在处理，请先检查请求和计费记录，再决定是否重新提交。

“请求参数与排错”显示本次模型、尺寸、画质、参考图片元信息及服务商提供的请求 ID（若有）。本地参数检查不调用服务商。向他人反馈错误前，请自己检查服务商原始错误消息中是否包含需删去的信息。

图片下载不跟随远程重定向；如果通道返回跳转下载地址，可尝试服务商支持的 Base64 返回方式。

## 保存与会话

生成的原始文件保存在 `generated/`，清空预览不会删除文件。刷新页面不会恢复旧预览，可从该文件夹查看历史文件。

API Key 与参考图只保留在当前页面和处理请求所需的内存中。刷新后需重新填写 Key、重新选择图片。浏览器只保存 API 地址、模型和设置，不保存提示词或图片。

默认随机端口可避免端口冲突；若希望后续启动复用浏览器中的设置，可用 `python app.py --port 7860`。端口被占用时换一个端口。应用仍只监听本机，不支持通过参数绑定公网地址。
